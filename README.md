# Video Downloader

A lightweight desktop video and audio downloader built with Python, Tkinter, and `yt-dlp`.

## Features
- Clean, modern Tkinter/ttk interface
- Asynchronous background downloading to keep the UI responsive
- Custom destination directory selection
- Quality/format selection (Best Video/Audio, Audio Only MP3)
- Real-time progress bar and status updates

## Installation

1. Ensure Python 3.10+ is installed.
2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:
```bash
python main.py
```

## Running Tests

Run the test suite using pytest:
```bash
pytest
```
